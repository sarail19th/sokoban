Box Pusher · pixel editor

Draw the character (every pose and direction, so you can paint the face and clothes) or the tiles (floor, wall, box, box on star, star), in 32×32 or 64×64. Copy the code and paste it on the game's start screen (Custom art). Works offline: just open this file.

What to draw

Frames

Size

Changing size converts this set (nearest neighbour). The game scales everything to the tile size.

Start the character from…

Takes a ready-made look (or the PAL/LOOK lines from the style editor pasted below) and turns all 16 frames into editable pixels. This replaces the current frames.

Looks

A look replaces only the sprites it covers.

Import PNG

Draw elsewhere (Piskel, Aseprite, …) and load a PNG into the selected frame. Transparent pixels stay transparent.


Colour

Swatches are the colours already in this frame. Use the eraser for transparency. Tip for faces/clothes: leave "same edit on all poses" on and paint on the front-facing frame, then fix the others.
